## 1. Цель продукта

Качественная офлайн-головоломка с арифметическими кроссвордами, большим разнообразием задач, ясным управлением, доказуемой помощью и приятным откликом. Мета усиливает обычное решение полей, не превращается в отдельную тяжёлую игру. Три опоры: Daily (вернуться завтра), недельная лига (сыграть ещё), мастерская (собирать коллекцию). Не делать клон всего Guru.

Первый запуск — реальное поле 1. Undo не возвращает уже израсходованный ресурс и не повторяет награду.

При активном Endless — безопасный переход в доступный экран и сохранение припаркованной попытки, не принудительная потеря. ## 4. LEAGUE — недельное очконабирательство (замена BRAINS-01 #22)

**Последнее решение DEC-2026-11-27-LEAGUE-GURU:** одна недельная Лига по Guru Brains, без дивизионов. Утверждённый состав: **1 игрок + 9 локальных компьютерных соперников**, вымышленные имена и собственные аватарки, одна недельная таблица, медаль за итоговое место, без интернета. Никакой зависимости от Race, Battle, Daily set или отдельного входа в боевую партию. Пользовательское название — **«Лига» / League**. Информация о компьютерных соперниках находится в правилах; не писать «Офлайн-лига», повторяющиеся «Бот» или технические параметры в основном интерфейсе. Никакой фальшивой сетевой активности или поиска реальных игроков. Новое решение владельца DEC-2026-11-27-LEAGUE-PRESENTATION заменяет прежние обязательные подписи. Источник: [Guru 4.17.0/26101374 Brains](https://github.com/DanilaH/mini-games-kit/blob/a994dc7910fd50f198f892e64a8203b764a921c1/research/games/crossmath/porting/guru-star-brains-native-20261125/README.md), [обе версии Guru R2](R2_APK_BALANCE_RU.md), [модель прежнего пилота](../porting/competition-pilot-20261126/model.mjs).
