# Crossmath · поручение разработчику

Разработай игру по **Crossmath_TZ_v1.0_RU.md**. Рядом лежит PDF с тем же текстом. В архиве находятся рабочий банк, маршруты, параметры баланса, рисунки коллекции, интерактивный образец и приёмочные сценарии. Все пути в ТЗ даны от корня этого архива.

1. Прочитай разделы 1–6 и 12–13 ТЗ. Проверь реальный репозиторий и ветку. Для нового Android-клиента используй указанный в ТЗ портретный bootstrap mini-games-kit. В существующем проекте сохрани действующие решения и точные версии зависимостей.
2. Открой product/ux_v10/Crossmath_Play.html локально в браузере. На поле 12 поставь 4 и 7 в верхнюю строку и 5 в столбец. Поменяй верхние фишки местами. Так должны работать управление и исправление ошибки в обычной игре.
3. Возьми готовые boards.json и routes.json из product/content_v09, баланс из product/meta_v08/config.json. Проектируй движок, подсказки и сохранения по правилам ТЗ. Данные исследованных приложений лежат отдельно в research и не являются игровым контентом.
4. Сдай первым этапы A–C. Нужна устанавливаемая тестовая сборка с полем, помощью, сохранением и однократной победой. Приложи коммит, инструкцию запуска, хеш сборки, результат испытаний и список непроверенного на устройстве. После среза переходи к этапам D–F.

## Проверка материалов после распаковки

Из корня комплекта, Python 3.12, стандартная библиотека:

```bash
python3 -B product/content_v09/verify.py
python3 -B product/content_v09/check_routes.py
python3 -B product/meta_v08/verify_meta.py
```

Ожидается PASS для 240 полей, 84 проверок выдачи и 32 проверок модели меты. Полный протокол браузерного образца — product/ux_v10/browser_checks.json. Подробные HC01–HC12 и M01–M12 находятся в contracts. Манифест SHA256SUMS.txt относится к поставленным байтам файлов до любых изменений.

Текущий баланс — версия 0.8, банк — content-v1, интерактивный образец — 0.10. Порог первой законченной карточки — 8 разных побед. Внутренние даты и номера старых документов в research обозначают этапы исследования. Решения для сборки изложены в сводном ТЗ 1.0.
