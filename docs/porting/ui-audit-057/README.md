# Crossmath 0.5.7 · аудит интерфейса

20 ноября 2026. Проверены [игровой код 7d2f3e0](https://github.com/DanilaH/crossmath-game/tree/7d2f3e03cc482b6b6fed28abc3cfe7dd8fc3bef6), веб-часть Preview APK 0.5.7 / 12, Guru Crossmath 3.5.2 и 4.17.0, EasyFun Offline Crossmath 1.1.9. Игровая разработка ведётся в PR #2. На момент проверки в main версия 0.4.0. Методика исследователя и pin игрового runtime различаются. Для исследователя — b6e7112, для сборки — 469928d.

**Первой я бы переделал навигацию между партиями.** Сегодня игрок открывает «Все режимы», чтобы посмотреть свой профиль, а в мастерской после получения первых счётов снова видит текущий прибор дважды и длинный перечень ещё пустых витрин. Оба экрана используют тёмные панели сходной формы. У ежедневной задачи, незаконченной партии и заработанной вещи разные причины для нажатия. Их стоит узнавать по дате, фрагменту реальной партии и виду самого прибора.

[Запись реальных касаний в 0.5.7 — главная → режимы → профиль → статистика](profile-route.gif). Задержки в записи сделаны для чтения.

**Решение владельца.** Сохранить игровые клетки, механику поля и текущую понравившуюся прибавку монет. Это относится и к виду выплаты. Пространство вокруг результата можно переразметить после фиксации эталона. Если у разработчика более свежая запись одобренного эффекта, эталоном служит именно она. В 0.5.7 подтверждены текст выплаты, изменение кошелька, квитанция и защита от повтора. Ранее показанный эскиз перелёта жетонов и арт-пак сами по себе не свидетельствуют о включении этого перелёта в APK.

### Как повторить два дефекта с приоритетом P0

1. Дойти до 15-й победы и нажать «На главную». В мобильном Chromium задать 320 × 568, touch и `html { font-size: 200% !important }`. Открыть мастерскую, вернуться и прокрутить к «Все режимы». Сохранить ширину visual viewport, `document.documentElement.scrollWidth`, результат реального касания и какое действие открылось. Одной проверки геометрии кнопки мало. На телефоне повторить тот же маршрут с системным увеличением.
2. На обычном масштабе открыть «Все режимы → Профиль и рекорды → Статистика по режимам». В длительности сыгранной кампании дробные секунды видны прямо в тексте. Значение длительности зависит от партии. Для автоматической проверки зафиксировать примеры из таблицы выше.

Рисовать соперника, магазин или кнопку просмотра видео только после согласования правил и работающего источника состояния. Внешний вид реального SDK — отдельная приёмка. |

## Как сделать оболочку узнаваемой

**Роль материала.** Светлая бумага — текущая задача или дата. Тёмно-зелёное сукно — место физического прибора. Тёмный стол — навигация и пауза. Янтарный — основное действие и существующие игровые предметы. Внутри одной смысловой группы достаточно разделителя; полный бортик оставить у реального листа, предмета или выбранного состояния. В тесте без цвета «Сегодня» отличает дата, мастерскую — предмет, текущую партию — её собственное равенство.

**Движение и звук.** Предлагаемая посадка листа при открытии — до 160 мс со смещением до 6 px. На готовом приборе допустим один проход света по только что добавленной детали. При повторном открытии предмет остаётся в конечном состоянии. Режим уменьшенного движения сразу показывает итог. Навигация, просмотр календаря и изменение громкости обходятся без новых обязательных звуков. Для вновь полученной детали использовать существующее событие зафиксированного результата и сравнить со зрительным касанием на Android. У одобренной выплаты остаются её звук, вибрация, геометрия и возможность сразу продолжить. Для обычных экранов достаточно цвета и типографики. Блюр, фоновые частицы и шейдеры не являются зависимостью ни одного задания.

**Ассеты и набор текста.** Генерацию имеет смысл попробовать на одном законченном приборе и его отдельных деталях. Фиксировать ракурс, источник света и одинаковый размер объекта в холсте. Экспортировать прозрачные слои, сравнить при ширине 48 и 160 px, затем решить судьбу остальных 11. Текст, числа, иконки действий, деления прогресса, состояния выбора и даты строятся средствами интерфейса. На 320 px и крупном шрифте дать тексту вторую строку. Заменять всё оформление сразу до просмотра первого набора слишком дорого.
