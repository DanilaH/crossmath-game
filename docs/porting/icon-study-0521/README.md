# Crossmath · иконки счётной мастерской

**Решение владельца от 22 ноября.** Для подключения выбран [упрощённый набор с новой золотой монетой](../menu-direction-0521/secondary/approved-icons.zip). Подробные варианты ниже сохранены как история исследования.

Авторская арт-проба для версии 0.5.21 / 26 и второго эскиза главной. 16 изображений сгенерированы общей таблицей, разделены и отцентрированы по видимому силуэту. Исходный запрос — PROMPT.txt. Художественное направление — чеканная латунь, зелёная эмаль, дерево и светлые счётные фишки. Пробная графика готова к подключению разработчиком.

| Файлы | Назначение |
|---|---|
| png/*.png | 16 прозрачных квадратов 256 × 256 для крупных изображений, наград и дальнейшего экспорта |
| web/*.webp | Те же 16 объектов 96 × 96. Кошелёк 24 CSS px, настройки и профиль 26 CSS px, меню 22–32 CSS px |
| controls/*.svg | Девять служебных знаков и две версии для команд «Сортировать» и «В лоток» при 23 CSS px |
| icons.json | Имена, размеры и соответствия |

**Где подключать.** В шапке использовать coin рядом с живым числом монет, settings на месте ползунков, profile на месте контура пользователя. Для служебных монохромных SVG задать цвет через currentColor во встроенном SVG или через CSS mask. У кнопок действий сохранить подпись, зону касания, управление с клавиатуры и доступное имя. У изображения внутри подписанной кнопки оставить пустой alt. Для пустой жизни использовать контур life-empty, рядом — текстовый счётчик.

**Детали и прогресс.** calendar предназначен для компактной кнопки календаря. Большой листок продолжает показывать день и месяц профиля. workshop — указатель на раздел. На верстаке и исторической награде используется соответствующее реальному прогрессу изображение прибора. Применение рисунка coin к награде согласовать с одобренной анимацией прибавки. Для сортировки и возврата в лоток при 23 px использовать sort-small и return-to-tray-small.

**Проверка.** Визуальная подстановка в браузерную версию 0.5.21 на ширинах 320 и 390 CSS px, в светлой и тёмной темах. Области кнопок профиля и настроек измерены по 48 × 48 CSS px. Нажатие открыло настройки, в игровом поле открылась помощь. В тёмной теме для тёмной эмали применена тонкая светлая кромка через drop-shadow. Проверка установкой на Android остаётся открытой.

**KIT IMPACT.** Для замены набора иконок просматривать характерные силуэты в шапке и в обеих темах на целевом размере. Предусмотреть отдельные упрощённые варианты многоэлементных команд для узкой панели.
