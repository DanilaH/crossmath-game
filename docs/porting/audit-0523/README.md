## Что проверено независимо

- SHA-256 файла Crossmath_0.5.23.apk — `9dcb0a5f915b272f230e7263b7396d13ab59949b802603aa967d88078a6323d1`. Все 10 файлов из ведомости web-ресурсов извлечены из APK и совпали с локальной release-сборкой. Браузер выше запускал эти извлечённые файлы.
- Успешны `npm run check` (118 тестов), `npm run build:release`, `npm run content:verify`, три штатных браузерных сценария и независимые касания на точном web-пакете. Проверка реестра дала 177 из 177 сопоставленных ID, в том числе 17 со статусом ACCEPTED.
- Переданная запись «победа → деталь» — Chromium 0.5.22, 390×844, 7,33 с, со звуковой дорожкой. Сверена её контрольная сумма. В протоколе разработчика указано, что дорожка собрана из вызовов WebAudio. Независимые кадры этого отчёта сняты заново на веб-ресурсах 0.5.23.
- На физическом Android ещё нужны установка поверх 0.5.21 с сохранением, уход в фон и возврат, системный шрифт/TalkBack, слышимый щелчок и вибрация при посадке. Публичный релиз имеет отдельную очередь F. Локальная дуэль M3 и подключение реального рекламного провайдера учитываются отдельно от редизайна.
