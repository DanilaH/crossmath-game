## 1. Что означает результат этого аудита

Мы инвентаризировали *все доступные локальные source surfaces/семейства по существующему материалу*, а не добились динамического покрытия каждого UI маршрута. В `SOURCE_FEATURES.json` теперь **265 источниковых ID**, включая 14 коммерческих и lifecycle-пробелов, которые были не выделены самостоятельными записями. В игре — **265 строк adoption ledger**, каждый со статусом и шагом. Число ID **не** доказывает полноту APK или реального продакшена. 5 базовых EasyFun prefab не являются самостоятельными страницами; из 64 одна `panelosa_prefab` всё ещё не привязана к подтверждённому маршруту. 265 путей в AOT Guru включают виджеты/design model и debug paths, не 265 живых экранов.

## 3. Недоказанные live системы — конкретные внешние блокеры

- **Guru 4.18 native APK:** оригинальный APKM/splits и package info, SHA/signature; публичная витрина или запись GUI не заменяет бинарник.
- **Guru full `CrossMathSolver.solve` и `stuck`:** текущая нативная проверка E43/E48 и ARM64 BL-depth ограничена, нужно end-to-end native strategy outcome/coverage на 12 899 задачах. Прогностическая ML-модель лишь `MODEL_TEST`, не алгоритм оригинала.
- **Активные remote cohorts/события:** Guru PuzzleFilter config, StarRace/Brains/Postcard/Adventure; EasyFun Event `hiddenNumber>0` и конкретный package SHA/дата.
- **Коммерческие контуры:** original live rewarded/show/revoke, IAP Play Billing entitlement/price/refund, GDPR/permissions, promo caps, Store prices and grant. App Store US и Google Play developer response — *другие типы источников*.
- **Телефон и сохранения:** original Android process kill, deep link/push, offline/online, physical sound/haptics, production Back/gesture/TalkBack и 0.5.24 in-place update. Наш releaseCheck APK подписан другим test cert по сравнению с 0.5.23, поэтому установка поверх без старого ключа не принята.
- **Человеческие данные:** скорость решения/ошибки/возврат D1/D7, эффективность склонения к подсказке/рекламе — нет проверенного telemetry/recruitment.

Это не повод вычеркнуть функцию. Она остаётся с конкретным sourceFeatureId и ожиданием первичного доказательства и решения владельца. Для каждого `DEFERRED` указаны stage и reason. Без server/phone source нельзя добросовестно пометить `MATCH` только по статическому коду.

## 4. Продуктовый порядок и приёмка без дублирования готового

**Уже готово по игре и не переделывать:** 0.5.24 реализует #6 (4 root tabs/Main-Day-Modes-Profile, Continue/New Game, отдельную мастерскую) и часть #5, 121 тест; live Android приёмка отсутствует. Следующее действие разработчика — реальный 320×568 / 390×844 Android запуск и 1× видео Back/scroll/обновления/звука/вибрации с source+APK SHA, затем устранение обнаруженных дефектов. Пользователь не поручал вводить платные SKU, расширять чатизированную аналитику или непрерывно перерассчитывать контент, поэтому это deferred.

**Исследователь без ожидания очередных сообщений:** по имеющимся APK и наработкам E29/H08–H12 продолжать разбор полного native solver и `stuck`; при недоступности стенда не притворяться исполнением. Для каждого оригинального live-эксперимента нужен конкретный SDK/server/device artifact; невозможность получить его сейчас — внешний blocker, а не выполненный тест. Не ограничиваться числом ID, использовать полную системную матрицу в [mini-games-kit](https://github.com/DanilaH/mini-games-kit/blob/research/crossmath-reference-audit-20261120/research/games/crossmath/porting/full-system-audit-20261123/README.md).

**KIT IMPACT · RESEARCH/REUSE:** дополнена методология объективной проверки source surface coverage (64 Unity prefab / 18 tables; 17 Dart UI families, 25 exact paths) и отдельные 14 механизмов. Runtime pin `469928d03f4bae5053e23db26e82187bedbc252e` не изменён.
