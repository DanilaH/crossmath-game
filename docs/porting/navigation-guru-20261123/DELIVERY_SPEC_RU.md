## 2. Предлагаемая адаптация в Crossmath

<Структура меню>

```text
[Главная]     [День]        [Режимы]        [Профиль]   ← постоянный bottom nav
    │            │             │               │
    ├─ Превью    ├─ Календарь  ├─ Кампания     ├─ Ранг
    ├─ Продолжить├─ Периоды   ├─ Спокойная    ├─ Достижения
    ├─ Новая     ├─ Трофеи    ├─ Испытание    ├─ Статистика
    ├─ День      ├─ Цели дня  ├─ Endless      ├─ Фильтры режима
    └─ Мастерская└─ Играть    └─ Battle (M3)  └─ Мастерская (ссылка)
```

**Критическое намеренное отличие:** у Guru третья вкладка **Battle**, в нашей текущей 0.5.23 локальная дуэль M3 ещё не реализована. Поставить сейчас отдельную таб-вкладку «Битва» с фальшивым Start неправильно. **Третий корневой раздел в нашем первом переносе — «Режимы»**, в него входят реально доступные Relax, Challenge, Endless, кампания; информацию об утверждённом в будущем Battle показать лишь при соответствующей стадии с честным состоянием. При полноценном M3 можно пересмотреть маркировку раздела по решению владельца. Информационная архитектура оригинала перенесена на уровне глубины, а не буквально имён вкладок. Этот шаг не является передачей поведения Battle, его source ID остаётся DEFERRED/MISSING.

**Главная:** сохранить ранее одобренную собственную миниатюру реального сохранённого поля и стиль. Продолжить — ведущая кнопка; Новая игра — видимое отдельное действие. Установить ежедневный и мастерской ярлыки компактно как вторичные. Убрать дублирующую кнопку «Все режимы» / диалог-«каталог» с основного маршрута; доступные режимы находятся в корневом табе. Приоритет Continue должен опираться на фактический активный слот, а не всегда на Campaign. Задача #5 по наградам 17→18 и 2/4 сохраняется.

**Новая игра:** нижний лист с текущими **действительными** доступными действиями Crossmath. Не показывать четыре сложности просто ради совпадения, если игра их не открывает, не менять банк/доступность. Если игрок уже имеет незавершённую партию, **выбор нового режима/поля** вызывает существующее подтверждение замены, отмена оставляет текущие фишки/жизни. Открытие листа — только UI, без записи нового попытки/траты.

**День:** одна верхняя панель (краткий заголовок+баланс), трофей/сеточный календарь со всеми нашими состояниями, одна видимая CTA для выбранного дня. Никакой крупной отдельной кнопки «← На главную»: у игрока есть вкладки. Работают реальная IANA-зона профиля, старые начатые поля и трофеи, не подменять дату телефона текущим системным UTC. Элементы контента можно скроллить, панель вкладок остаётся доступной.

**Режимы:** на странице, а не в диалоге — кампания с коротким отрезком полей (зафиксированная отдельная претензия к #5), Relax и Challenge, Endless с текущим забегом/рекордом и явной ценой завершения активного забега. Модальные окна только для короткого выбора/подтверждения. Не терять существующие пороги открытия 3/5/15.

**Профиль:** верхний ранг/недавний знак, ниже сгруппированные показатели. Внутренний segmented-control по реальным режимам (Campaign/Free/Daily/Endless), а выбор сложности показывать только при наличии сравнимых показателей, не создавать несуществующую статистику. Переход из профиля в мастерскую — по собственному видимому entry. Числа прошлых попыток в мигрированных профилях могут оставаться partial и должны так помечаться.

**Мастерская:** **не пятая корневая вкладка**. Вход с главной и из профиля; отдельный глубокий экран со своим компактным Back к исходному разделу и текущим состоянием 12 приборов. Не менять атомарные квитанции, пороги, остаток, animation flight/contact/stamp и повторное открытие старой детали.

**Игровой экран:** нижний tab bar скрыт, остаются board/tray/toolbar. Back, жест Android/пауза и финальное окно не должны случайно уходить в другой активный слот. После выбора «Главная» возвращать к 4-tab shell. Звук и вибрация по уже утверждённым переключателям.

**Визуальная идентичность:** весь интерфейс Crossmath сохраняет локальный Rubik, собственные 16 WebP, монету, белую/тёмную темы, деревянные детали и тихий игровой стол. Разделяем source navigation и Crossmath художественное решение; не используем чужие 3D-награды, фоны, blue gradients, рейтинговые иконки.

## 3. Точки изменения

- `src/meta/types.ts`: маршруты root/nav и прежние screen; не добавлять `Battle` как доступный режим до M3.
- `src/ui/metaView.ts`: Main/Daily/Mode page/Profile вместо модального каталога, даты/мастерская/return-to-origin.
- `src/ui/gameUi.ts`: единый bottom bar, активная вкладка, Back/focus, блокировка перехода во время атомарной записи. Результат/игра не содержат bottom bar.
- `src/app/session.ts`: durable screen и сохранение parked слотов, навигация без изменения попытки, сохранение выбранной Daily даты.
- `src/ui/home.css`, `menuScreens.css`, `src/style.css`, `index.html`: адаптивный shell, 48px реальная зона в игре, safe area, прокрутка, состояния 100/120/150/200% и reduced motion.
- `src/meta/career.ts`: используется для существующих показателей, **не** переписывать историю или выдачу.

**Два несовместимых старых предписания:** прежнее `docs/porting/menu-direction-0521/IMPLEMENTATION_TZ_RU.md` и [issue #5](https://github.com/DanilaH/crossmath-game/issues/5) требуют отдельный «Все режимы», отдельные «← На главную» и верхние блоки. Новое решение владельца **заменяет только архитектуру навигации**, но сохраняет одобренные тексты, типографику, арт, монету, награды и gameplay. В issue #5 остаются валидны исправления завершённой коллекции и Rubik/кошелька; замечания по дорожке кампании и календарю/мастерской проверять уже в новой IA, чтобы два агента не воссоздавали старый экран.
