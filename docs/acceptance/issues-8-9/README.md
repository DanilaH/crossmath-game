## №8 · Help / Explain

- 11 исходных примеров из ТЗ прошли с прежним выбором шагов и evidence для двух готовых планов. Отдельный контроль `count=1, exhausted=true` даёт незавершённую проверку. Независимая проверка отклоняет изменённое доказательство, устаревшую ревизию и повторы жетонов по прежним правилам.
- 60 проверок интерфейса Chromium при 100% на 320×480, 320×568 и 390×844. RU в светлой теме и EN в тёмной. Описание целиком видно после выбора, кнопки в нижнем ряду доступны касанием. Чтение сохранения до и после Preview, смены выбора и Back даёт те же данные.
- Четыре контрольные раскладки Endless дают одинаковое нейтральное сообщение при несовместимости и отсутствии шага. Начатый забег сохраняет solo, жизни и раскладку. Корректная полная раскладка до Submit остаётся игрой; помощь не ставит отметку о правильном равенстве.
- На первом поле готовый Explain применился один раз. Из 120 списались 60 монет, начислилась обычная победа +10, сохранились 70 монет и одна квитанция. Холодная загрузка сохранила результат. Повтор operation ID проверен отдельно.
- Сравнение до/после и GIF сняты в Chromium при 320×568, RU, светлой теме, Campaign. Поле 902 — контрольный пример с единственным решением из ТЗ. GIF показывает Explain → сообщение → возврат к полю, 2,58 с. Контрольные суммы в [evidence.json](evidence.json).

## №9 · ADS / команды баннера

- На базе `bbae4ac` повторены два дефекта и два успешных контроля из ТЗ. После отвергнутого show или hide та же команда терялась.
- Unit проверяет повтор show/hide, смену цели в обе стороны после resolve и reject, отсутствие немедленного цикла, зависшие запросы статуса и квитанций, отдельные блокировки, поздние ответы и один заключительный hide при dispose.
- Три маршрута Chromium с тестовым адаптером на 320×480, 320×568 и 390×844. Вход в Help вызвал hide, закрытие вызвало show. После ошибки повтор сработал на штатном refresh. Закрытие fullscreen на фоне и возврат на передний план с открытой Help не вызвали show. Одновременно оставался максимум один незавершённый вызов.
- С зависшим hide прошли пауза → поле → победа +10 → «Следующее поле» → главная → продолжение. Поздний ответ оставил баннер скрытым на главной. Продолжение отправило show. Dismiss без earned не выдал кредит. Последовательности команд записаны в [evidence.json](evidence.json).

## Сборка и пределы проверки

`npm run check` — 145 тестов. `npm run content:verify` и все три штатных сценария Chromium прошли. Прошли синхронизация release web и Gradle debug/releaseCheck. Подписанный APK проверен по содержимому, версии, подписи v2 и выравниванию 16 KiB. В DEX проверен `setTextZoom(100)`. SHA-256, сертификат и исходник в [evidence.json](evidence.json).

Тестовый APK использует `com.danilah.crossmath.releasecheck`. Физическая проверка Help, Back, звука и вибрации открыта. Native-проверка баннера и live SDK ожидают провайдера. Chromium фиксирует команды тестового адаптера; отрисовка рекламы и impression требуют отдельного наблюдения.

**KIT IMPACT · REUSE.** Использованы действующие App Lifecycle, DurableReceiptQueue и контракты источников. Три записи сохраняют RESEARCHED / PARTIAL. [Реестр](../../porting/ADOPTION_LEDGER.json).
