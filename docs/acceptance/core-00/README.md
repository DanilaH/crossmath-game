Для Reveal предварительный просмотр не пишет в сейв. Apply проверяет ID попытки, ревизию, допустимость цели и точный список возвращаемых фишек. Оплата и расстановка записываются одной транзакцией. Повтор операции не списывает деньги. Undo возвращает прежние позиции без повторной оплаты или возврата монет. Логика Explain осталась прежней.

## CI · ширина числа внутри фишки

[Исходный запуск CI](https://github.com/DanilaH/crossmath-game/actions/runs/45965389709) падал на измерении после Explain. На первом кейсе 320×480, поле `cm-own-02-114`, Reveal здесь не участвует. После появления длинного объяснения шаг сетки составляет 22,18 px. Внутри фишки 18 px, текст `19` в DejaVu Sans занимает 19,14 px при прежней формуле. Широкий системный шрифт воспроизводит тот же assert на исходной сборке. Сам CI не записывал название шрифта раннера.

Размер двузначного числа теперь ограничен по ширине фишки с учётом двух рамок. На том же кейсе DejaVu Sans занимает 17,20 px при доступных 18 px. Размер однозначных чисел, операторов, всей сетки и сенсорных областей сохраняется. Исходный критерий `range.width <= clientWidth + 1` проверяется для всех чисел и дополнительно с DejaVu Sans.

## Воспроизведение

- `npm run check`, `npm run content:verify`, `npm run test:browser`. Explain проверяется на всех 515 полях с пустого старта и с частичным заполнением.
- `node tools/core00-browser.mjs` снимает режимы, лист выбора, главную, задания, записи профиля, открытие Challenge, победу в Relax и Reveal. Для кадров исходной сборки используется `CORE00_BASELINE=1 CORE00_WEB=<dist-0522edb>`. Матрица 320×480, 320×568 и 390×844, RU/EN, светлая и тёмная темы. Android Back проверяется через подставной мост Capacitor в Chromium.
- `npm run android:sync:release`, Gradle `assembleDebug assembleReleaseCheck` и `tools/verify-apk.py --kind releasecheck` проверяют собираемость и точное содержимое APK. `com.danilah.crossmath.releasecheck` устанавливается отдельно от основной игры. Физическое устройство, обновление с ранее выданным производственным сертификатом и реальный рекламный SDK требуют отдельной проверки.
- Два сценария локального переноса фишки связаны с `easy-hint-local-replace-return` и `easy-hint-no-tray-transfer-not-swap`. Приоритет выбранной клетки и атомарное списание остаются контрактом Crossmath.
