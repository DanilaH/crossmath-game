## Запись и устойчивость награды

Оба ролика сняты непрерывно по одному сценарию на Chromium с эмуляцией касаний. База использует веб-ресурсы подписанного 0.5.21. В 0.5.22 после победы сумма кошелька сразу стала 450, а кнопка продолжения осталась доступной. Деревянный щелчок запускается в обработчике контакта детали. Звуковая дорожка MP4 составлена из фактических буферов WebAudio по времени их запуска. [Наблюдения и измерения](observations.json).

При искусственном отказе записи последнего хода награда не появилась, баланс и инвентарь остались прежними. Штатный повтор сохранил +15 и 2/4. Уход в фон в фазе полёта вывел финальное состояние без отложенного звука. Холодная загрузка прочитала ту же квитанцию без повторной выдачи. Эпизоды с 17 → 24, 2 → 5 и 27 → 29 прогнаны как тестовые диапазоны порогов. Обычная выдача остаётся один шаг за новое поле.
