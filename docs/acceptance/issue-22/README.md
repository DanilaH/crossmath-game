## Игрок и интерфейс

Вход: **Профиль → Офлайн-лига → Вступить в лигу**. Четыре корневые вкладки сохранены; из лиги Back возвращает в профиль. В игре нижняя навигация скрыта. На таблице девять собственных вымышленных соперников явно подписаны «Бот», заголовок говорит «Офлайн-лига». Собственные простые аватарки и медали используют Rubik и существующие цвета; монета, поле и анимации начисления сохранены.

Вступление добровольное. Обычная игра доступна без него. Вступившие начинают с нуля, календарные отметки до вступления исключены из всех девяти планов. После окончания итог и медаль сохраняются автоматически, затем игрок отдельно вступает в следующую неделю. Пропущенные недели не создают историю или награды. На победе одна строка показывает подтверждённые очки; старый результат подписывает очки той недели.

Пакет сохраняет экспериментальную выдачу `d4-v2` №16 и «Банк · Lab» №17. У лабораторного банка отдельное сохранение и бесплатная помощь; он не участвует в очках обычной лиги. Обычные 515 ID и все прежние выплаты сохранены. Обычные release/content-lab/issuance-pilot сборки не включают участие в лиге; совместимые league-данные сохраняются. Веб-проверка исключает входы лабораторий из release, Gradle блокирует league-lab для стора.

## Правила эксперимента, до числового согласования

| Параметр | В этой сборке |
| --- | --- |
| Неделя | Понедельник 00:00 — следующий понедельник 00:00, конец исключён; сохранённая зона профиля |
| Вступление | Доступно из профиля, текущая оставшаяся часть недели; без платы |
| Обычные победы | Campaign / Relax / Challenge / Daily |
| Очки сложности | Easy 1, Normal 2, Hard 3, Expert 4; Hell использует текущую core-категорию Expert |
| Повтор ID | Один зачёт за неделю; глобально решённый ID снова доступен в новой неделе |
| Explain / Reveal | Те же очки, без скрытого штрафа; расход помощи прежний |
| Ничья | Игрок выше; боты в устойчивом порядке |
| Дневные цели A1/A2, B1/B2, C1/C2, D1/D2/D3 | Собственные диапазоны `[6,11)`, `[4,8)`, `[3,6)`, `[1,4)` |
| Медали | Места 1/2/3 — золото/серебро/бронза при ≥1 очке; остальные и нулевой счёт — медаль участника с итоговым местом |
| Материальные награды | Нет league-монет, подсказок или XP; реклама не умножает очки |

Все эти числа — кандидат для плейтеста, не установленные live-параметры Guru. В активной неделе сохранены версия политики, веса, диапазоны, правила медалей, период, seed и все девять планов. `league-lab-1` неизменяем по смыслу: следующая калибровка требует новой версии и сохранения поддержки старой.

| Подтверждённое правило | Наша адаптация |
| --- | --- |
| `calculationDailyTarget` 0xa21f40: min + nextInt(max−min) | Та же верхняя исключённая граница, собственные уменьшенные диапазоны |
| `calculationCollectByTarget` 0xa20d00: девять шаблонов долей, четыре местных окна | Девять индивидуальных шаблонов; окна 08:10–11:00, 11–16, 16–19, 19–23; фиксированные календарные отметки |

Special catch-up Guru с configured max не копируется: наш catch-up читает сохранённые отметки. Темп не зависит от частоты открытия, места игрока, помощи, рекламы или покупок. Исходные live-границы недели, призы, eligibility и server activation остаются UNKNOWN. Lifetime hat, main/temp, гонки, дуэли, дивизионы и онлайн в этот пакет не входят. Source IDs: `guru-brains-week`, `guru-brains-plan`, `guru-brains-hat`, `guru-brains-hat-own-ongoing`.

## Атомарность и восстановление

`Save.league` — необязательное расширение текущего schema 4 и ключа `crossmath.save.v1`. Начальные профили не меняются до вступления. Все записи идут через GameSession / SaveRepository. Очки создаются вместе с ordinary win receipt, монетами и результатом, публикация только после успешного commit. Реклама, рендер и анимация не владеют начислением. Один puzzleId и одна квитанция учитываются не более раза за неделю.

Время транзакции снимается перед записью и сохраняется с победой. Поздний ACK не переносит её в другую неделю. Команда, обрабатываемая уже после конца, очков старой недели не получает. Итог содержит одно стабильное medal receipt и снимок десяти мест. После холодного запуска, повтора операции или прыжка времени второй награды нет.

При вступлении local-time окна разрешаются в UTC. На чтении сохранённые метки **не генерируются заново**, даже если обновились правила зоны: проверяются структура, границы и контрольная сумма замороженного плана. Это защита от повреждения, не offline-античит. DST использует фактические 167/169 часов в проверенных неделях New York; проверена зона с четвертьчасовой поправкой Kathmandu. Rollback не отнимает прогресс, временно останавливает очки лиги и показывает причину; основной кор доступен. Forward jump закрывает только реально вступившую неделю, без пустых медалей за пропуски.

Повреждение опциональной лиги изолируется в `leagueQuarantine`: исходные данные сохраняются, новый вход блокируется, корректные монеты/партия/обычная победа не откатываются к старой резервной копии. Изоляция записывается до показа экрана. Автоматического стирания истории или перезапуска лиги нет. Дальнейшее восстановление повреждённой лиги остаётся отдельной процедурой; основной прогресс доступен.

## Балансная модель

[Полные метрики](../../experiments/league22/MEASUREMENTS.json) получены действующим runtime-алгоритмом на действующих полях и шестипозиционных ротациях: 4 200 синтетических сценариев, 600 составов, вступление в понедельник/пятницу/воскресенье. Это не наблюдённые человеческие сессии и не прогноз удержания.

| Семь полных дней | Очки | Место min / median / max | Доля золота в 200 составах |
| --- | ---: | --- | ---: |
| Одно Easy в день | 7 | 10 / 10 / 10 | 0% |
| Два Relax в день | 18 | 7 / 7 / 8 | 0% |
| Шесть Relax в день | 56 | 1 / 2 / 3 | 28,5% |
| Два Challenge в день | 46 | 3 / 3 / 4 | 0% |
| Шесть Challenge в день | 140 | 1 / 1 / 1 | 100% |
| По шесть Relax в выходные | 16 | 7 / 7 / 9 | 0% |

Главный открытый вопрос — позднее вступление. Оставшаяся часть планов короче; после последнего воскресного окна один Easy может дать первое место. Нулевой результат получает только участие. Правила допуска и медалей нужно выбрать до постоянного включения, вместе с весами и целевым темпом. В ходе недели компенсация по месту не применяется.

Активный пример — 5 496 байт, один компактный итог — 956 байт; 52 результата около 49,7 KB, 1 100 — около 1,05 MB. Это оценка по конкретному примеру, не максимальный размер всего старого профиля. Архив не хранит старые полные планы и журналы тиков. Максимум очков при одном зачёте всех 515 полей текущего банка — 1 140; отдельно проверяется четырёхзначная вёрстка.

Шрифт 100%, главные CTA доступны до прокрутки. Это браузер и controlled clock.
- `node tools/content03-browser.mjs` — сохранённый эксперимент №17, 876 сочетаний. `build:issuance-pilot` и `tools/issuance-pilot-browser.mjs` сохраняют №16.
- Gradle debug/releaseCheck. Проверка точного APK: `verify-apk.py … --kind releasecheck --issuance-pilot --content-lab --league-lab --out …`. Release UI-исключения проверяются без ослабления старых glyph-fit assertions.

Физическое Android-исполнение, обновление поверх установленной игры и пальцевый плейтест остаются открытыми: устройство не подключено. Native Back в браузере не подменяет телефон. Результаты CI, APK SHA/сертификат, кадры и исходные записи приложены к передаче.
