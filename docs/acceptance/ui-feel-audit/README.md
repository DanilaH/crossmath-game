## P2, подтверждённые локальные UX-проблемы
- UX-01 — compact home preview: 320x480 RU/EN light/dark, glyph overflow/сплющивание. src/ui/resumePreview.ts, home.css, league.css (48px preview cap). Вписывать с сохранением пропорций по обеим осям; при недостатке места — ясная упрощённая миниатюра, не растягивать числа. Continue/New/Daily/Workshop/League/нижняя навигация доступны, карточки не прыгают.
- UX-02 — League back: Home -> League -> Back возвращает Profile во всех 12 combos. Это текущий контракт/тест, не потеря данных; предлагается UX-изменение: сохранять origin Home/Profile, одинаково для стрелки и Android Back; корректный cold-launch fallback, не ломать существующий album origin. src/ui/gameUi.ts, src/ui/metaView.ts, navigation tests. 
- UX-03 — Daily shortcut: выбрать 01.11, Home показывает 23.11, нажать today's Daily -> открыта 01.11 (12/12). Карточка сегодняшней задачи открывает effectiveDay; корневая Day сохраняет прошлый выбор. Не сбрасывать ни одну партию, не менять date policy/экономику; src/ui/gameUi.ts, metaView.ts.
- UX-06 — pause/settings/restart на короткой высоте: подтверждение Restart может быть под fold; handler раскрывает без reveal/focus. Явно показать предупреждение и выбор, сохранить понятный Cancel/Continue; help title после выбора подробной помощи уходит при scrollIntoView, сделать читаемый контекст без обрезки содержимого. Не скрывать действия, не увеличивать случайно платёж. src/ui/gameUi.ts, dialog CSS. Проверить прокрутку, Back, фокус, длинные RU/EN, кнопку восстановления.
