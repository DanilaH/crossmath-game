# Пилот рекламного cooldown · Crossmath 0.5.24 / 29

25 ноября 2026. База Crossmath `6f8a259dca7e87e1033c3f1cb4256a935885bf97`, реализация `d37cd305f597d38074929af1fbe3080aeac13549`. [PR игры №4](https://github.com/DanilaH/crossmath-game/pull/4) · [PR геймкита №152](https://github.com/DanilaH/mini-games-kit/pull/152).

Источник `guru-ad-cd-reward-additive` в Guru 4.17.0 / 26101374 подтверждает статическую формулу прибавления времени к остатку дедлайна. Отсчёт по активному времени, предел накопления, обработка no-fill и связь с подтверждённой квитанцией — условия пилота Crossmath. Для Guru факт `onAdHidden` не является доказательством выдачи награды. [Исследование и исходные адреса](https://github.com/DanilaH/mini-games-kit/blob/f4cca83706abc576c21d2b6eeb488562042126b9/research/games/crossmath/porting/guru-commerce-callbacks-20261125/README.md).

| Событие | Правило Crossmath |
| --- | --- |
| Первые пять уникальных побед | Переход на следующее поле без interstitial. Начиная с шестой, действует общий дедлайн. Источник времени — сохранённые секунды активной игры. |
| Подтверждённый interstitial | Дедлайн не раньше чем через 180 активных секунд. Повторный и устаревший колбэки не обновляют время. |
| Earned rewarded | Прибавляет 120 секунд к максимуму текущего времени и дедлайна. Предел остатка при накоплении 420 секунд. Уже более длинная защита сохраняется. |
| No-fill, отказ или отмена interstitial | Следующая победа может запросить рекламу спустя 30 активных секунд при отсутствии более долгой защиты. Результат каждой партии резервируется один раз. Отмена rewarded сама по себе дедлайн не меняет. |
| Перезапуск с незавершённым запросом | Сохранённая резервация защищает 180 активных секунд с момента вызова. После позднего подтверждения применяется его итог. |
| Старое сохранение | При первом событии новый дедлайн наследует максимум прежних `lastInterstitial + 180` и `lastReward + 120`. Без обратного накопления. Схема сейва остаётся 4. |

Снимок дедлайна записывается тем же сериализованным сохранением, что квитанция и награда. Подтверждение провайдеру идёт после записи. При сбое записи тот же earned можно доставить повторно. После подтверждённой записи повтор не меняет баланс и защиту. Решение владельца по `guru-rv-hint-interstitial-fallback` — отложено.
