# Crossmath 0.5.9 · меню при крупном шрифте

Проверены веб-файлы из APK 0.5.8 и 0.5.9. Chromium touch, 320 × 568 CSS px, сохранение после 15 побед. Масштаб задан размером корневого шрифта.

| Масштаб | Нижняя граница «Все режимы», было → стало | Высота содержимого меню, было → стало |
| --- | --- | --- |
| 100% | 539 → 517 px | 392 → 360 px |
| 120% | 569 → 521 px | 469 → 377 px |
| 150% | 611 → 525 px | 531 → 403 px |
| 200% | 771 → 547 px | 777 → 446 px |

При 200% маршрут «Мастерская → назад → Все режимы → Спокойная игра» проходит касаниями без свайпа. В селекторе видны четыре режима, названия и подписи помещаются в одну строку. Проверенные зоны касания от 48 CSS px. Базовый шрифт навигации на узких экранах растёт с 16 до 24 px при увеличении корневого шрифта с 100% до 200%. Тест относится к Chromium. Системный шрифт Android отдельно не проверен.

Стартовое поле и первая выплата совпали с 0.5.8 попиксельно при обычном шрифте на 320 × 568 и 390 × 844. 72 модульных теста, три браузерных сценария, Gradle debug и R8 releaseCheck прошли.
