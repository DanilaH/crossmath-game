## DEC-2026-11-24-SOURCE-BASED-IMPLEMENTATION

Источник решения — прямое сообщение владельца от 24.11.2026: «надо использовать собственную реализацию на основании декомпилированного кода который тоже будет скопирован в отчёты, а так же архитектурные приёмы. Репозиторий закрыт».

1. Декомпилированный/native код предоставленных референсов служит непосредственной основой собственной реализации: алгоритмы, структуры данных, ответственность компонентов, потоки управления, state machine и порядок callback адаптируются к текущей игре. Clean-room изоляция разработчика не требуется.
2. Релевантный исходный код копируется в закрытый mini-games-kit report/annex с version/build, SHA исходного файла, инструментом/версией, method/RVA и границами фрагмента. Точный вывод инструмента, восстановленный вручную псевдокод и собственный игровой код маркируются раздельно.
3. Датированная проверка видимости в PR #7: mini-games-kit — private, crossmath-game — public. Оригинальные выдержки остаются в закрытой исследовательской части; consumer содержит собственную реализацию и ссылки. Это сохранение исходного решения, а не новая проверка настроек репозиториев.
4. Вести связь sourceFeatureId → исходный фрагмент → алгоритм/архитектура → собственная адаптация → приёмка. NATIVE_STATIC, NATIVE_ISOLATED, MODEL_TEST и ORIGINAL_RUNTIME/Android не повышаются друг до друга автоматически. Готовые vendor-файлы не включаются в продукт автоматически.
5. Норма заменяет blanket-запрет декомпиляции и обязательную clean-room изоляцию для данного поручения. [Локальный Reference Protocol](kit-guidance/REFERENCE_PROTOCOL.md) уточняется поверх сохранённого guidance/runtime pin; [историческая методика source-assisted](https://github.com/DanilaH/mini-games-kit/blob/06a01d5c1f7af3cdf8013c9ce0f6a691d086af78/docs/agent-workflows/REFERENCE_PROTOCOL.md) остаётся доступной. Продуктовые решения о балансе, сохранениях и SDK принимаются отдельно.

Собственная реализация Crossmath опирается на проверенный декомпилированный код и архитектуру референсов. Точные фрагменты оригиналов, версии, SHA и методы хранятся в закрытом геймките. В публичном Crossmath остаются собственный код, решения и ссылки на доказательства. [Исходные материалы](https://github.com/DanilaH/mini-games-kit/blob/06a01d5c1f7af3cdf8013c9ce0f6a691d086af78/research/games/crossmath/porting/decompiled-source-evidence-20261124/README.md).

Все подсистемы core, выдачи, onboarding, помощи, feel, наград, календаря, Battle, соревнований, LiveOps, рекламы, IAP, возврата, аналитики, сохранений и платформы получили независимую source-system matrix.

[Consumer gap audit](porting/FULL_REFERENCE_GAP_AUDIT_2026-11-23.md) и [adoption ledger](porting/ADOPTION_LEDGER.json) определяют актуальные стадии, не исторические числа 177/195/222/246 в прежних датированных документах. Системная инвентаризация **не доказывает достижимость всех screen paths в оригинальном Android**; для active remote flags, direct IAP/ads receipts, push, физической вибрации и полного native solve есть явные UNKNOWN. Нельзя автоматически включать дорогие системы, подменять сохранения, копировать чужую графику или утверждать, что 0.5.24 стала полноценным Guru. **Историческая игровая APK этого аудита: 0.5.24 / 29, source `0401140d`**, runtime kit pinned `469928d03f4bae5053e23db26e82187bedbc252e`.
